# Semiconduttori-SupplyChain-Analytics-2026
Questo progetto end-to-end analizza l'interazione tra le tensioni geopolitiche, le interruzioni della catena di approvvigionamento (Supply Chain) e le performance finanziarie dei leader di mercato dei semiconduttori nel corso del 2026. L'obiettivo è dimostrare competenze avanzate di Data Analytics e modellazione relazionale (Star Schema).
